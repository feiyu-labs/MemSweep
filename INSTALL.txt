MemSweep
========

English
-------
1. Right-click install.cmd -> Run as administrator.
   Installs to C:\Program Files\MemSweep and registers a logon task plus a desktop shortcut.
2. Tray icon: left-click opens the panel, right-click for the menu, middle-click cleans instantly.
   Global hotkey: Ctrl+Shift+M (change it in Settings > Advanced).
3. Uninstall: right-click uninstall.cmd -> Run as administrator.
   Settings and logs stay in %APPDATA%\MemSweep (delete the folder to remove them).
4. Portable use: put an empty MemSweep.ini next to MemSweep.exe before the first
   launch, and settings and logs stay in that folder.

简体中文
-------
1. 右键 install.cmd -> 以管理员身份运行。
   安装到 C:\Program Files\MemSweep，并创建开机计划任务与桌面快捷方式。
2. 托盘出现图标：左键打开面板，右键菜单，中键秒清。
   全局热键：Ctrl+Shift+M（可在 设置 → 高级设置 中修改）。
3. 卸载：右键 uninstall.cmd -> 以管理员身份运行。
   配置与日志保留在 %APPDATA%\MemSweep（如需彻底清除请手动删除）。
4. 便携使用：首次启动前，在 MemSweep.exe 旁边放一个空的 MemSweep.ini，
   配置与日志就保存在同一个文件夹里。

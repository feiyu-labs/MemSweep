This release fixes ARM64 system detection, keeps System status counts consistent, removes the desktop shortcut on uninstall, and polishes wording across the app and docs.

- Show ARM64 instead of x64 in the About dialog on Windows on ARM64.
- Match the System status warning count on the main screen with the System status sheet, and sum pagefile usage across multiple drives.
- Ask for confirmation before starting background system actions, and notify you if diagnostics export or `.wslconfig` updates fail.
- Remove the desktop shortcut when running `uninstall.cmd`, and try a clean exit before stopping an old instance during installation.
- Polish English and Chinese wording across the main screen, settings, dialogs, and documentation.

---

这个版本修复了 ARM64 架构识别和系统状态计数不一致的问题，卸载时会一并清理桌面快捷方式，并整理了应用内外的界面与文档文案。

- 在 Windows on ARM64 设备上，「关于」页面现在会正确显示 ARM64。
- 主屏「系统状态」卡片与系统状态弹窗改用同一套统计口径，并支持汇总多块磁盘上的页面文件大小。
- 系统操作先在界面完成确认再转入后台执行，导出诊断或写入 `.wslconfig` 失败时会给出明确提示。
- 运行 `uninstall.cmd` 时会同时删除桌面快捷方式；`install.cmd` 升级时会先尝试让旧实例正常退出。
- 全面校对了界面、安装说明和仓库文档的中英文表达。

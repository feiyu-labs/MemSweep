This release strengthens memory reclamation on Windows 11, adds dynamic background CPU and disk I/O throttling to keep foreground apps smooth, groups multi-process apps in the Processes view, and verifies what stays freed 10 seconds after cleaning.

- Clear higher-priority standby cache safely during automatic cleans when free memory stays starved and paging is calm, avoiding 0 MB passes, while backing off repeat trims under heavy memory compression.
- Lower busy background CPU and disk I/O priority alongside memory priority when Efficiency mode is on, restoring normal priority as soon as they settle or you switch back to them.
- Group multi-process apps like browsers and editors in the Processes view so you can see their combined memory, protect an entire app with one click, or right-click to free all of its background instances.
- Preview per-area reclaimable memory and top commit-heavy apps in `/dryrun` and exported diagnostics, plus log net retained memory 10 seconds after each manual clean.
- Set manual cleanup to Balanced by default, keeping page combining for Deep cleanup and clean-when-away.

---

这个版本针对 Windows 11 改进了缓存清理和后台调度策略，在「进程」弹窗里按应用合并显示内存，并会在手动清理 10 秒后自动复核净保留效果。

- 空闲内存长期见底而「已缓存」积压较多、系统换页平稳时，自动清理会安全清理全量待机缓存；压缩内存较高时会自动拉长对同一进程的重复修剪间隔。
- 在高级设置中开启「后台效率模式」后，持续高占用 CPU 的后台程序会自动降低 CPU、磁盘 I/O 与内存优先级，空闲或切回前台时立即恢复。
- 「进程」弹窗把浏览器、编辑器等多进程应用合并成一行，显示总内存与进程数，左键可一键保护整个应用，右键可一次释放它的全部后台实例。
- `/dryrun` 与导出诊断报告现在会按区域列出可回收空间和提交占用最高的应用，并在每次手动清理 10 秒后记录实际保留下来的内存与硬缺页变化。
- 手动清理默认使用「均衡」力度（清理后台与系统缓存），把耗时较长的页面合并留给「深度」清理和离开时维护。

## English

### Notifications no longer cover your game

`Balloon()` never looked at what you were doing, so a tray notification could pop over a fullscreen game. Every notification now passes one gate first: `SHQueryUserNotificationState()` must report `QUNS_ACCEPTS_NOTIFICATIONS`, otherwise nothing is shown — exclusive-fullscreen games, presentation mode, Focus Assist / quiet hours and fullscreen apps are all covered by that state.

Many modern games run **borderless fullscreen**, where Windows still reports "accepts notifications", so a second check looks at geometry: if the foreground window covers its whole monitor (desktop and taskbar excluded), MemSweep stays quiet too.

- Automatic-clean notifications are now silent (`NIIF_NOSOUND`): reclaiming memory is not worth a sound.
- Suppressed notifications are dropped, not queued — coming back from a game should not greet you with a stack of balloons.
- Two non-intrusive channels always carry the information: the tray tooltip now ends with `cleaned 2m ago`, and the line under the main button says whether the last clean was automatic or yours.

| Situation | Behaviour |
|---|---|
| Manual clean, desktop visible | Tray notification (mutable via silent mode) |
| Automatic clean, ≥64 MB reclaimed, desktop visible | Silent notification, at most once per 10 min |
| Fullscreen game / presenting / Focus Assist / panel open | Nothing; tray tooltip and panel update instead |
| Hovering the tray icon | Last clean time — never covers anything |

### Package

- `MemSweep-v1.9.14-x64.zip` and `MemSweep-v1.9.14-arm64.zip`, each with `install.cmd`, `uninstall.cmd`, `INSTALL.txt`, `LICENSE` and a matching `.sha256`.
- `build.cmd test` passes with zero warnings; `/selftest` covers the notification-state gate.

## 简体中文

### 通知不再挡住游戏画面

`Balloon()` 之前完全不看用户此刻在做什么，全屏游戏时照样弹。现在所有通知先过一道判断：`SHQueryUserNotificationState()` 必须报告 `QUNS_ACCEPTS_NOTIFICATIONS`，否则整条不发——独占全屏游戏、演示模式、专注助手/勿扰时段、全屏应用都包括在内。

很多现代游戏是**无边框全屏**，系统状态仍然报"接受通知"，所以再补一层几何判断：前台窗口铺满所在显示器（排除桌面与任务栏）时同样保持安静。

- 自动清理的气泡改为静音（`NIIF_NOSOUND`）：内存回收不是要紧事，不值得一声响。
- 被压掉的通知直接丢弃、不排队——从游戏里回来不该先吃一串积压气泡。
- 信息仍有两个不打扰的出口：托盘悬浮提示末尾新增 `上次清理 2 分钟前`，面板按钮下那行写明上次是自动还是手动。

| 场景 | 行为 |
|---|---|
| 手动清理、桌面可见 | 托盘气泡（静默模式可关闭） |
| 自动清理、回收 ≥64 MB、桌面可见 | 静音气泡，十分钟最多一次 |
| 全屏游戏 / 演示 / 勿扰 / 面板开着 | 不弹，只更新托盘提示与面板 |
| 悬停托盘图标 | 上次清理时间，从不遮挡 |

This release adds hybrid CPU core steering to efficiency mode, makes System status open instantaneously without PowerShell, surfaces heavy commit charge in the Processes list, and trims tray memory and background work even further.

- Efficiency mode now steers busy background apps onto efficiency cores on hybrid Intel CPUs and secondary CCDs on dual-CCD AMD CPUs, then hands scheduling back to Windows when they settle or return to the foreground.
- System status now reads Windows memory mechanisms and page file usage directly so the sheet opens right away, detects Store-installed WSL2, and reliably applies custom sizes to system-managed page files.
- The Processes list now calls out apps holding heavy commit charge inline, and fresh installs no longer show duplicate "Not running" entries for built-in VM protections.
- Automatic cleaning now pauses working-set trims during heavy disk paging spikes, while tray mode skips loading the UI graphics stack until you open the window and lets you resume paused auto-cleaning right from the home switch.

---

这个版本为后台效率模式加入了异构核心分流，让系统状态页面无需启动 PowerShell 即可秒开，在进程列表里直接标出高已提交应用，并进一步压低了托盘常驻开销。

- 后台效率模式在 Intel 大小核与 AMD 双 CCD 处理器上会自动把高占用后台导流到能效核或次核心域，等它回落或你切回前台时立即把调度权交还系统。
- 系统状态页面改用 Windows 原生接口直读内存机制与分页文件，打开即刻显示，同时支持识别商店版 WSL2，并修复了系统自动管理分页文件点调整时未能生效的问题。
- 进程列表会在已提交内存明显偏高的应用旁直接标出提交量，全新安装时也不再把内置保护的虚拟机显示成两条未运行条目。
- 磁盘换页繁忙时自动清理会主动避开工作集修剪；开机静默常驻托盘时不再预加载界面图形库，处于暂停状态时点击首页开关即可直接恢复自动清理。

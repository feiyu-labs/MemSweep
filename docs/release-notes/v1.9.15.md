Right-clicking the tray icon opens the menu at the cursor, not in the top-left corner of the screen.

- The tray callback reports the click position in one argument and the event in another; the menu was reading the event id as coordinates.
- When the shell reports no position, the menu now falls back to the current cursor location.

右键托盘图标，菜单现在出现在你点击的位置，不再跑到屏幕左上角。

- 托盘回调把事件和光标坐标放在两个不同的参数里，菜单把事件号当成了坐标。
- 系统不上报坐标时，回退到当前光标位置。

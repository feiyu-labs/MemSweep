This release removes the white flash around the settings panel when it opens and makes the panel appear noticeably faster.

- Open the settings panel without the bright edge that used to flash around it before the dimmed background settled.
- Show panels sooner: interface updates now reach the screen in about a millisecond instead of tens of milliseconds, and only the moving card is redrawn while it slides in.
- Fix the occasional "0 KB / 0 KB" reading on the main screen right after startup or a clean.

这个版本去掉了打开设置时四周一闪而过的白色边框，并让面板出现得更快。

- 打开设置面板时，背景遮罩从第一帧起就是暗的，不会再先露出一圈浅色边距再变暗。
- 界面刷新到屏幕的耗时从几十毫秒降到约一毫秒，滑入动画只重绘卡片移动的区域。
- 修复启动或清理后主屏偶尔显示「0 KB / 0 KB、可用 0 KB」的问题。

This release makes the numbers after a clean match what actually happened, and keeps the panel responsive while a clean is running.

- The "available" number shown right after a clean now comes from the clean itself instead of a five-second-old reading, so it agrees with the amount freed.
- Gauge and cleaning animations stop while a panel is open, so opening settings during a clean no longer triggers constant full-window redraws.
- Turning efficiency mode off now clears any priority marks left by a clean that was already running.
- The tray tooltip keeps its commit figure current.

这个版本让清理完成后的数字与实际结果一致，并让清理进行时打开面板也保持轻快。

- 清理完成后显示的「可用」改用本次清理测得的数值，不再引用最多滞后五秒的旧数据，与「已释放」保持对得上。
- 面板打开时暂停主屏的仪表与清理动画，清理过程中打开设置不再持续触发整窗重绘。
- 关闭「后台效率模式」时，正在进行的清理刚打上的优先级标记会在下一轮自动撤销。
- 托盘悬停提示里的已提交数值变化时也会及时刷新。

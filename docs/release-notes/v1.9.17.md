A code review of the whole source tree found eight small defects; all are fixed here, and the README now documents where the product sits in its category and what comes next.

- The hotkey recorder no longer accepts keys it cannot display (numpad and punctuation keys were silently reverted to Ctrl+Shift+M after a restart).
- A failed startup-task change no longer leaves the setting pointing the opposite way.
- Deep clean now respects silent mode, and the tray icon retries registration if the shell is not ready at logon.
- The pagefile check adapts to the machine's own RAM instead of one developer's 24–64 GB preset, and its action applies to every configured pagefile.
- Foreground focus is now tracked by window events instead of a five-second poll, so an app you switched away from keeps its two-minute protection.
- The single-instance check no longer has a race window, config writes refuse to replace a good file with a truncated one, and the system sheet's pagefile row no longer warns on machines that were not the developer's.

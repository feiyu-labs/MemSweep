This release protects multi-process apps and input methods more completely under heavy memory pressure and keeps automatic cleaning calmer during disk paging.

- Foreground browsers and Electron apps now keep their same-name helper, GPU, and renderer processes protected too, and switching back to a window restores its helper processes together.
- Built-in protection now covers Windows and common Chinese input methods (TextInputHost, WeType, Weasel, Sogou, and Baidu IME), so typing stays responsive without adding them to the whitelist by hand.
- Automatic cleaning holds back background trimming earlier when disk paging rises and trims fewer apps per pass, keeping heavy workloads smoother.
- Automatic full standby-cache purges now wait longer between runs and skip busy paging periods, while high usage with enough available memory still waits for background apps to go idle.

---

这个版本在高内存压力下更完整地保护多进程应用和输入法，并在磁盘换页繁忙时让自动清理更克制。

- 前台浏览器和 Electron 应用的同名渲染、GPU 等子进程现在会一起受到保护，切回窗口时也会同时恢复它们的调度优先级。
- 系统和常见中文输入法进程（微软输入法、微信输入法、小狼毫、搜狗、百度）已加入内置保护，不用手动添进白名单也能保持打字跟手。
- 磁盘换页升高时会更早暂缓后台内存回收，每次自动清理也会限制同时处理的后台进程数量，减少高负载下的短暂卡顿。
- 自动清理全量已缓存内存现在间隔更久，并且只在磁盘换页平稳时才执行；内存占用偏高但可用空间还够用时，也会继续等待后台程序真正闲置后再清理。

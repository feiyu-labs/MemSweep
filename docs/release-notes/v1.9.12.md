## English

### The global hotkey is now yours to set

`Ctrl+Shift+M` was hard-coded in two places and the only control was an on/off switch. **Settings → Advanced → Global hotkey** now shows the current combination as a chip; click it and press the combination you want.

- Press-to-record, following the same interaction as Windows Terminal and VS Code: holding only the modifiers previews `Ctrl+Alt…` without committing, `Esc` keeps the previous combination, clicking away cancels, and auto-repeat is suppressed.
- Three failures are reported separately, and recording stays open so you can just try again: no modifier, a reserved combination (`Alt+Tab`, `Alt+F4`, MemSweep's own `Ctrl+S`/`Ctrl+Enter`), or one another program already owns — decided by a real `RegisterHotKey` call, not a guess.
- Registration is transactional: if the new combination cannot be registered, the previous one keeps working and the setting is only written after success.
- At startup, a combination taken by something else falls back to `Ctrl+Shift+M`; if that also fails the hotkey is turned off rather than left pretending to work.

The configuration gains a readable `hotkeyCombo=Ctrl+Shift+M` key (`Win+Ctrl+Alt+Shift+<Key>`, order and case insensitive, letters, digits, F1–F24 and Space).

### Engineering

- Parsing, formatting and the reserved list are pure functions covered by 12 new `/selftest` assertions.
- `ApplyHotkey()` is the only registration entry point; nothing else calls `RegisterHotKey` directly.
- Fixed the resource version: `FILEVERSION`/`PRODUCTVERSION` had been stuck at `1,9,3,0` while the string version moved on.

### Package

- `MemSweep-v1.9.12-x64.zip` (414,208 bytes) and `MemSweep-v1.9.12-arm64.zip` (350,720 bytes), each with `install.cmd`, `uninstall.cmd`, `INSTALL.txt`, `LICENSE` and a matching `.sha256`.

## 简体中文

### 全局热键可以自己改了

`Ctrl+Shift+M` 之前写死在两处，界面上只有开关、不能改。现在**设置 → 高级设置 → 全局热键**会把当前组合键显示成一个 chip，点一下然后按下想要的组合即可。

- 按下即录制，交互与 Windows Terminal、VS Code 的快捷键录制一致：只按修饰键时实时预览 `Ctrl+Alt…` 但不提交，`Esc` 保留原组合，点到窗口外自动放弃，长按不会连触。
- 三种失败分别说明原因，且录制状态不退出，可以直接再按一次：没带修饰键 / 保留组合（`Alt+Tab`、`Alt+F4`、MemSweep 自己的 `Ctrl+S`、`Ctrl+Enter`）/ 被其他程序占用——后者由真实的 `RegisterHotKey` 结果决定，不靠猜。
- 注册是事务化的：新组合注册失败会回滚到旧组合继续生效，只有注册成功才写入配置。
- 启动时若配置的组合已被占用，回落默认 `Ctrl+Shift+M`；两者都不可用才关闭热键，不会留下"显示已开启却没有热键"的状态。

配置新增可读的 `hotkeyCombo=Ctrl+Shift+M`（`Win+Ctrl+Alt+Shift+<Key>`，顺序与大小写无关，支持字母、数字、F1–F24、Space）。

### 工程质量

- 解析、格式化与保留组合判断都是纯函数，`/selftest` 新增 12 条断言覆盖。
- `ApplyHotkey()` 是唯一的注册入口，其余位置不再直接调用 `RegisterHotKey`。
- 修掉资源版本号不一致：`FILEVERSION`/`PRODUCTVERSION` 长期停在 `1,9,3,0`，与字符串版本脱节。

### 安装包

- `MemSweep-v1.9.12-x64.zip`（414,208 字节）与 `MemSweep-v1.9.12-arm64.zip`（350,720 字节），各含 `install.cmd`、`uninstall.cmd`、`INSTALL.txt`、`LICENSE` 与同名 `.sha256`。

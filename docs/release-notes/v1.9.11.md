## English

### Smaller binary, calmer home screen

- The icon carries six key sizes (16/20/24/32/48/256) instead of nine; Windows scales from the nearest neighbour, and `.rsrc` dropped from 28,672 to 18,944 bytes.
- Process-name handling collapsed into one `NormalizeProcName()` used by the whitelist, the built-in protection list and the process sheet, replacing eight duplicated to-lower/strip-`.exe` implementations.
- Built-in protection is a static table instead of a hash set built at startup, and the process sheet dedupes with one map plus one sort.
- **The home screen gained a foundation**: the two bare text links at the bottom became compact cards showing the current top memory consumer and a system-health summary, which also removed the dead space under the clean button.
- Compilation now runs with `-Werror`, so a warning fails the build locally and in CI alike.

### Documentation

- `README.md` is English with `README.zh-CN.md` as the Chinese mirror, one file per language, each with language-matched screenshots.

### Package

- `MemSweep-v1.9.11-x64.zip` (403,456 bytes) and `MemSweep-v1.9.11-arm64.zip` (340,480 bytes).

## 简体中文

### 体积更小，主屏更稳

- 图标保留 6 个关键尺寸（16/20/24/32/48/256），其余由 Windows 从相邻尺寸缩放；`.rsrc` 从 28,672 降到 18,944 字节。
- 进程名处理收敛为一个 `NormalizeProcName()`，保护名单、内置保护表与进程面板共用，替换掉 8 处重复的"转小写 + 去 `.exe`"实现。
- 内置保护从启动时动态构造的哈希集合改为静态表；进程面板改为一次 map 去重 + 一次排序。
- **主屏底部补上了基座**：原先两行悬空的文字入口改为两张紧凑卡片，直接显示当前最占内存的应用与系统健康摘要，顺带消掉了清理按钮下方的大片留白。
- 编译开启 `-Werror`，本地与 CI 一样，出现警告即失败。

This release keeps efficiency mode focused on background apps that actually use memory, instead of tagging every small helper process.

- Efficiency mode now applies to background apps above your "Only clean apps over" threshold (128 MB by default) instead of every process.
- Automatic passes do less work per run and no longer mark dozens of small helpers.

---

这个版本让「后台效率模式」只作用于真正占用内存的后台应用，而不是把所有小进程都标记一遍。

- 后台效率标记现在按「只清理超过」的阈值（默认 128 MB）生效，不再覆盖几十 MB 的小进程。
- 自动清理每轮需要处理的进程更少，不再给大量小工具逐个设置优先级。

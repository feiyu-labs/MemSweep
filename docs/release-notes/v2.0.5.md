This release cuts idle CPU use when the window is behind other apps or in the tray, stops pointless repeat auto-cleans, and protects visible and audio-playing windows from background throttling.

- Leaving the window open behind another app or hidden in the tray now stops its UI timers and idle glow, dropping background CPU use to near zero.
- Automatic cleaning waits after a manual clean instead of firing seconds later, skips empty low-priority cache sweeps, and eases off when consecutive runs free little memory.
- Visible side-by-side or second-monitor windows and apps playing audio are no longer lowered by efficiency mode, and background CPU throttling waits for real contention so busy builds stop flapping.
- Background efficiency mode now also curbs high-frequency background timer wakeups on Windows 11 and hands processes cleanly back to Windows when restored.

这个版本消除了面板切到后台或藏进托盘时的空转耗电，减少自动清理的无用空跑，并保护屏幕可见和正在发声的窗口不被误降级。

- 面板被其他窗口盖住或收进托盘后，会立即停掉界面定时器与呼吸动效，后台 CPU 占用降到接近零。
- 手动清理完成后会同步重置自动清理冷却，不再刚清完几秒又自动补跑；低优先级缓存为空时直接跳过，连续收益很小时自动拉长间隔。
- 双屏或分屏里肉眼可见的窗口，以及正在播放音乐、视频或语音通话的程序，不再被后台效率模式降级；后台 CPU 让路只在整体繁忙时介入，避免编译进程每隔几秒反复升降。
- 在 Windows 11 上，后台效率模式同时抑制闲置后台的高频时钟唤醒，恢复时把调度权完整交还系统。

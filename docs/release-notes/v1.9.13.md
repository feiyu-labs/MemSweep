## English

### Automatic cleaning is now visible

Automatic cleaning used to run completely silently: tray notifications were reserved for manual cleans, and the panel normally sits in the tray — so whether it had cleaned at 85% was anyone's guess. In one rotated log the engine ran 140 automatic passes, reclaiming 130 MB on average and 1.19 GB at best, and none of it was observable.

- Automatic passes now report **only when they actually reclaim memory**: a tray notification at 64 MB or more, at most once every ten minutes, never while the panel is open, and never in silent mode. A pass that frees nothing still says nothing.
- The line under the main button now distinguishes the source: `last auto clean 2m ago · freed 130 MB` for automatic passes, `last clean …` for ones you started.
- The auto-clean description reads `reclaims idle background above 85%` instead of `cleans above 85%` — the engine attempts whatever is safe to reclaim, which is not the same as promising a large drop.

### Notes

- No back-off was added for zero-gain passes; they keep running at the configured interval. Log timings show 0–16 ms per pass, but the `last clean` timestamp will keep moving — that is the engine working, not a display bug.

### Package

- `MemSweep-v1.9.13-x64.zip` (415,232 bytes) and `MemSweep-v1.9.13-arm64.zip` (351,232 bytes), each with `install.cmd`, `uninstall.cmd`, `INSTALL.txt`, `LICENSE` and a matching `.sha256`.
- `build.cmd test` passes with zero warnings; `/selftest` covers the new notification policy with six assertions.

## 简体中文

### 自动清理现在看得见了

之前自动清理全程静默：托盘气泡只给手动清理，而面板常年藏在托盘里，所以"到 85% 到底清没清"完全靠猜。一次轮转日志里，自动清理实际执行了 **140 次**，平均回收 **130 MB**、最高 **1.19 GB**，却没有任何可感知的反馈。

- 现在自动清理**只在真的回收了内存时**提示：回收 ≥64 MB 发一次托盘气泡，十分钟内最多一次，面板开着时不打扰，静默模式完全不发声。空跑（回收 0）依旧一个字都不说。
- 主屏按钮下那行区分来源：自动清理写 `上次自动清理 2 分钟前 · 释放 130 MB`，自己点的那次仍写 `上次清理 …`。
- 自动清理那行的说明改为 `高于 85% 时清理可回收的后台内存`——引擎做的是"尝试回收能安全回收的部分"，不等于承诺一定掉一大截。

### 说明

- 零收益的空跑没有加退避，仍按设定间隔执行。日志显示单次耗时 0–16 ms，但 `上次清理` 的时间戳会一直刷新——那是引擎在跑，不是显示故障。

### 安装包

- `MemSweep-v1.9.13-x64.zip`（415,232 字节）与 `MemSweep-v1.9.13-arm64.zip`（351,232 字节），各含 `install.cmd`、`uninstall.cmd`、`INSTALL.txt`、`LICENSE` 与同名 `.sha256`。
- `build.cmd test` 零警告通过；`/selftest` 为新的通知策略覆盖了 6 条断言。
